# ASCALab Website Starter

## Setup

```bash
npm install
npm run dev
```

Then open the localhost URL printed by Vite.

## Included

- React + Vite
- Tailwind CSS v4
- React Router
- Framer Motion
- Lucide React icons
- `/` landing page starter
- `/quiz` timed quiz starter
- ASCALab SVG logo in `/public`
- Placeholder contact form ready to wire to Google Apps Script / Google Sheets
